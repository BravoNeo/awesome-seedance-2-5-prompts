# Contributing

Open an issue with the creator’s X video link and the post or same-author reply containing the prompt. Include the exact model attribution and mention any reference the prompt needs. We accept standard Seedance 2.5 examples with an identifiable match between the clip and prompt.

Check for an existing entry with the same source video, prompt or scene before proposing an addition. Keep posts and media linked at their source. Use your own wording for edited prompts and preserve the camera, motion and storytelling details that make the example useful.

Run `node scripts/validate.mjs` before submitting a catalog update.
